# Timothy Nguyen — academic website

Personal academic website of Duc Thanh (Timothy) Nguyen, Predoctoral Research Associate at the Wharton School, University of Pennsylvania.

Live website: https://timothynguyen-vnm.github.io/

## Update the website

Edit the HTML and CSS files in this repository and push to `main`. GitHub Pages publishes the repository root. No build or dependency installation is needed.

- `index.html`: homepage, biography, and portrait
- `research.html`: research experience; working papers and publications are intentionally blank
- `teaching.html`: teaching experience
- `contact.html`: contact information
- `assets/Nguyen_CV.pdf`: downloadable CV; navigation opens it directly in a new tab
- `cv.html`: compatibility redirect to the PDF
- `style.css`: responsive styling
- `robots.txt` and `sitemap.xml`: search engine discovery

Preview locally with `python3 -m http.server 8000`.

The supplied portrait is used with the owner's authorization. The Wharton logo is the institutional asset used at https://mariusguenzel.com/img/wharton.png and links to the Wharton School. Institutional trademarks remain their owners' property.

## Google Search

The site includes a sitemap, canonical URLs, descriptive titles, and Person structured data. To request indexing, add the live URL as a URL-prefix property in Google Search Console, complete ownership verification, submit `sitemap.xml`, and use URL Inspection to request indexing of the homepage. Indexing and search rankings are determined by Google.
